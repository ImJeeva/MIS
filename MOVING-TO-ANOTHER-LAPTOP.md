# Moving MIS to another laptop

## 1. Install these first (on the new laptop)

| Software | Version | Download | Notes |
|---|---|---|---|
| **Node.js** | LTS (20 or 22) | https://nodejs.org | Includes `npm`. Just click through the installer. |
| **Python** | 3.10 – 3.12 | https://www.python.org/downloads/ | **Tick "Add python.exe to PATH"** on the first installer screen. |
| **MySQL Community Server** | 8.x | https://dev.mysql.com/downloads/mysql/ | During setup, **write down the root password**. |
| **VS Code** (optional) | latest | https://code.visualstudio.com | Nice editor + built-in terminal. |
| **Git** (optional) | latest | https://git-scm.com | Only if you want to clone instead of copy. |

> Alternative to installing MySQL: install **Docker Desktop** (https://www.docker.com/products/docker-desktop/)
> and later run `docker compose up -d db` from the project root. Then use
> `DATABASE_URL="mysql://mis:mispass@localhost:3307/mis"` in step 4.

## 2. Copy the project

Copy the whole `MIS` folder to the new laptop (USB drive, Google Drive, GitHub — anything).

**Do NOT copy these** (they are big and get rebuilt anyway):

- `node_modules/`  (there are 3: root, `server/`, `client/`)
- `ai-service/.venv/`
- `server/uploads/`  (seed images are regenerated by the seed script)

**DO copy this one** (don't skip it — it's the trained model, ~80 MB):

- `ai-service/model/pneumonia_densenet169.keras` + `model_meta.json`, **if you've
  trained it** (see the Colab step). Without it the AI falls back to a much
  weaker guess-only mode.

Everything else (all source code, `package.json`, `package-lock.json`, `prisma/`,
`requirements.txt`, `.env` files) **must** be copied.

Quick way to make a clean zip on this laptop (PowerShell, from inside `D:\3.0\sivayou\abarna`):

```powershell
$src = "MIS"; $dst = "MIS-transfer"
robocopy $src $dst /E /XD node_modules .venv .git dist
Compress-Archive -Path $dst -DestinationPath MIS-transfer.zip -Force
```

## 3. Install project dependencies (on the new laptop)

Open a terminal in the copied `MIS` folder.

```bash
# backend
cd server
npm install

# frontend
cd ../client
npm install

# AI service
cd ../ai-service
python -m venv .venv
.venv\Scripts\activate           # Windows
pip install -r requirements.txt

# root (lets you run client + server together)
cd ..
npm install
```

## 4. Point the app at the new MySQL

Create the database (use MySQL Workbench, or the `mysql` command line):

```sql
CREATE DATABASE mis CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Edit **`server/.env`** and set `DATABASE_URL` to the new laptop's MySQL user +
password. URL-encode special characters in the password (`@` → `%40`,
`#` → `%23`):

```
DATABASE_URL="mysql://root:THE%40NEWPASSWORD@localhost:3306/mis"
```

## 5. Create tables + demo data

```bash
cd server
npx prisma generate
npx prisma migrate dev
npm run db:seed
```

## 6. Run it — ONE command

From the project root:

```bash
npm run dev
```

That starts the backend, frontend, **and** the AI service together in one
terminal. Wait for `client` to print `http://localhost:5173`, then open that.

Log in with `admin@mis.local` / `Passw0rd!` (quick-login buttons are on the
sign-in page). Press `Ctrl+C` once to stop everything.

> This relies on `python` being on PATH. If `npm run dev` says "python is not
> recognised", reinstall Python with **"Add python.exe to PATH"** ticked, or run
> the AI service by itself: `cd ai-service && python -m uvicorn app:app --port 8000`.

### Checklist

- [ ] Node.js installed (`node -v` works)
- [ ] Python installed (`python --version` works)
- [ ] MySQL installed and running, root password known
- [ ] Project folder copied (without `node_modules` / `.venv`)
- [ ] `npm install` run in `server/`, `client/`, and root
- [ ] `pip install -r requirements.txt` run in `ai-service/`
- [ ] `server/.env` → `DATABASE_URL` updated with the new password
- [ ] `npx prisma migrate dev` + `npm run db:seed` run
- [ ] `npm run dev` + `uvicorn app:app --port 8000` running
